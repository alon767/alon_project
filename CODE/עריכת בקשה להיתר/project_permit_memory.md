## לקחים טכניים
- **חלון פלט ריק של pyRevit = כנראה שגיאת import.** בכל כלי: קובץ trace בראש script.py + try/except שרושם traceback. אני קורא את הקובץ ישירות.
- שמות API שטעיתי בהם: `ElementOnPhaseStatus` (לא ElementPhaseStatus). `ElementType.Name` ב-IronPython לא אמין → `SYMBOL_NAME_PARAM`.
- IronPython 2: חלוקת int/int היא שלמה (`float()`); אין f-strings; לא לשים ElementId ב-json (להמיר ל-int).
- זיהוי רצפה: נקודה-בתוך-Sketch (`floor.SketchId` → Profile), לא מלבן חוסם (רצפת ממ"ד היא אלמנט אחד ענק). כשיש כמה — הגבוהה מנצחת.
- בטקסט של רוויט, שבירת שורה היא `\x0b`; השוואת שמות מתעלמת מרווחים ומפיסוק.
- מילת מפתח "chair" תפסה "Armchair" — להיזהר ממחרוזות קצרות.
- YAML של bundle: גרשיים (`"`) בתוך מחרוזת → להשתמש ב-`״` או במירכאות בודדות.
- DWFX: ZIP/XPS. עברית ב-Glyphs היא CP862 בסדר חזותי — `dwfx_tools\fixhebrew.ps1` מפענח ל-text.tsv; `xpsregion.ps1` מרנדר אזור (Indices שבורים → להסיר). ב-PowerShell `$w` ו-`$W` הם אותו משתנה.
- פרויקט מרובה-מחשבים: לקרוא את הקובץ הזה מחדש לפני שמירה/עדכון zip, כדי לא לדרוס עבודה ממחשב אחר.
- **אלון לא תמיד מאתחל את רוויט אחרי התקנה**, ואז רצה גרסה ישנה (קרה ב-28.09.26, כשהגיע צילום של "באג" שכבר תוקן). לכן `permit_write.VERSION` נכתב לשורה הראשונה של כל הרצה ב-trace. **לפני שמנתחים תוצאה — לוודא בקובץ ה-trace שהגרסה הנכונה רצה.** גם מיקום תוויות הדירות נרשם ל-trace (`apartment label ...: clear / least overlap / no room fits`).
