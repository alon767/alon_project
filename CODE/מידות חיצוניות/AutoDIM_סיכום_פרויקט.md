## איך להתקין על מחשב חדש

1. לוודא ש-pyRevit מותקן (`winget install pyRevit.pyRevit`) ומחובר ל-Revit (2024/2025).
2. לחלץ את `AutoDIM_Install.zip` לתוך `%appdata%\pyRevit\Extensions\`.
3. **חשוב**: לסגור את Revit, למחוק את `%APPDATA%\pyRevit\Cache`, ולפתוח את Revit מחדש (Reload רגיל לא מספיק לשינויי מבנה/אייקונים).
4. לוודא שנוצר טאב **AutoDIM** בריבון עם 4 הפאנלים.

## מבנה הריבון (AutoDIM.tab) — v22

| פאנל | כפתור | פעולה |
|---|---|---|
| מידות חיצוניות | דרום / צפון / מזרח / מערב | `run_facade(...)` — יוצר L1/L2/L3 + תגיות UK לחזית שנבחרה |
| מידות פנימיות | מידות X / מידות Y | `run_axis_dim("X"/"Y")` — קו חיתוך (2 קליקים) → מידה רציפה על הקירות שנחצו |
| **מידות עם פתחים** (חדש) | מידות X / מידות Y | `run_axis_dim_openings("X"/"Y")` — כמו למעלה, אבל כולל גם פתחי דלתות בקירות קרובים (`opening_dim_offset`), עם גובה הדלת כ-Below text |
| **מידות עם פתחים** | מדידת קירות | `run_wall_dim()` — לחיצה על קיר בודד → מידה הכוללת את הפתחים שבו |
| הגדרות | סגנון מידה | בחירת DimensionType (ליניארי בלבד) לשימוש בכל הכפתורים |
| הגדרות | סגנון UK Tag | בחירת FamilySymbol (מקטגוריית תגיות חלון) לתגיות ה-UK |
| הגדרות | **מרחק מקיר** (חדש) | קובע `wall_dim_offset` — המרחק הבסיסי שממנו מחושבים L1/L2/L3 |
| הגדרות | **Multiple** (הועבר לכאן מ-מידות פנימיות) | checkbox — כשמסומן, מידות X/Y (גם הרגילות וגם עם פתחים) חוזרות על עצמן עד Esc |

כל הלוגיקה מרוכזת בקובץ אחד: `lib/dim_utils.py`. הכפתורים עצמם הם שכבה דקה שקוראת לפונקציות משם. כפתור Multiple ומרחק מקיר משתמשים גם ב-`__selfinit__.py` נפרד (רץ בטעינת pyRevit) כדי לשחזר את מצב האייקון/הערך השמור.

- **v22 — FINAL** (02–03.07.26):

  - **הגדרת "מרחק מקיר"** (`wall_dim_offset`) — מחליפה מרחקים קבועים; L1/L2/L3 מחושבים ממנה.
  - **Multiple עבר לפאנל הגדרות**, עם `__selfinit__.py` נפרד שפותר סופית את בעיית איפוס האייקון בטעינה.
  - **אופטימיזציות ביצועים**: איחוד collectors לדלתות, סריקת גיאומטריה אחת (refs+width יחד), הסרת DEBUG alerts ולוגים מיותרים.
  - **תיקון 03.07.26**: כפתור "סגנון UK Tag" נוקה וחודד (סינון קטגוריה ישיר, `prompt=` להצגת הסגנון הנוכחי).
  - מאומת ומסונכרן על **שני מחשבים** (User + offic) — זהה בייט-לבייט.
- **v23 — CURTAIN_WALL** (13.07.26): תמיכה מלאה במידות ותיוג Curtain Wall בפאנל "מידות חיצוניות" בלבד (`run_facade`/L3):
  - **זיהוי הטבעה (Embedded Wall)**: קיר מסך רגיל מוטבע בקיר מארח (`Wall.SuperComponent`) — בדיוק כמו חלון "בתוך" קיר. אם נמצא מארח, קיר המסך מצטרף לרשימת הפתחים של הקיר המארח (יחד עם חלונות/דלתות) במקום לקבל קו L3 נפרד — כך שהתוצאה היא רצף מידה אחד רציף.
  - **שרשרת גיבויים** לקיר מסך "חופשי" (לא מוטבע) או בלי גיאומטריה בכלל: גיאומטריה עצמית (רקורסיבית לתוך GeometryInstance, עם DetailLevel=Fine) → ref משכן צמוד → Reference Plane קבוע שנוצר בקצה האמיתי (לא כפילויות בהרצות חוזרות).
  - **חריג ל-`is_low_wall`**: קיר מסך נכלל תמיד בחזית בלי קשר לגובה (לפני התיקון, קיר מסך נמוך מ-200 ס"מ הודר לגמרי כאילו הוא מעקה שקוף).
  - **גובה**: Unconnected Height מוצג כ-Below text על סגמנט הפתח בקו המידה.
  - **UK Tag ל-Base Offset**: תגית אמיתית (לא טקסט על המידה) ממשפחת Wall Tag ייעודית `UK_קיר מסך` שנבנתה בפרויקט, לכל קיר מסך עם Base Offset > 0 — ממורכזת ברוחב קיר המסך, באותו קו גובה שבו תגיות UK לחלונות.
  - **כיוון תגית**: `TagOrientation` (גם לחלון וגם לקיר מסך) נקבע אוטומטית לפי כיוון החזית (Horizontal בדרום/צפון, Vertical במזרח/מערב) — לפני התיקון היה קבוע ל-Horizontal ודרש סיבוב ידני בחזיתות אנכיות.
  - **מאומת רק על מחשב User** — טרם הועתק/נבדק על "offic".

## נקודות טכניות קריטיות להמשך

- קבועי בסיס: `CM=0.0328084`, `TOLERANCE=10cm`, `LOW_WALL_HEIGHT=200cm`. L1/L2/L3 כיום נגזרים מ-`wall_dim_offset` (ברירת מחדל 100 ס"מ, בפועל בפרויקט הזה — 400 ס"מ בשני המחשבים).
- הבניין כולל שקעים ו-step-backs — דיוק גאומטרי קריטי. `get_dim_face_refs` מוצא פנים אמיתיות מגאומטריה (`ComputeReferences=True`).
- **הגדרות (`autodim_settings.json`)**: `multiple`, `dim_style`, `uk_tag_style`, `cw_tag_style` (חדש ב-v23, ברירת מחדל `"UK_קיר מסך"`), `wall_dim_offset`, `opening_dim_offset` — ספציפי לכל מחשב, **לא** כלול בחבילת ההתקנה בכוונה (כל מחשב/פרויקט שומר את הבחירות שלו).
- **quirks חשובים של pyRevit** (ראו `project_autodimensions_memory.md` לפירוט מלא):
  - שינוי אייקון/מבנה דורש מחיקת `%APPDATA%\pyRevit\Cache` + restart מלא — Reload רגיל לא מספיק.
  - splitbutton גורם לקונפליקט שמות ב-ribbon — להשתמש תמיד ב-pushbutton נפרד.
  - IronPython: אין f-strings, אין list comprehensions מורכבים. עברית: `u"..."`.
  - `__selfinit__.py` (קובץ נפרד, לא פונקציה) + `script.get_button().set_icon(path)` — השיטה היחידה שעובדת לשחזור אייקון בטעינה.
